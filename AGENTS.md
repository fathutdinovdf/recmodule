# Модуль управления рекомендациями — правила работы над проектом

**Правила проекта целиком лежат в `CLAUDE.md` в этом же каталоге. Прочитай его
перед работой — здесь только то, чего там нет.**

Коротко о главном, чтобы не начать не с того:

- Работа идёт в **`app/`** — Next.js 15 + React 19 + TypeScript + PostgreSQL
  в Docker. npm и сборщик здесь есть.
- **`макет/`** — замороженный статический эталон вёрстки, **только чтение**.
  Экраны переносятся оттуда в `app/` разметкой и CSS один в один.
- Состояние работы и план — в **`app/BRIEF.md`**, читать первым.
- Запуск: `cd app && npm run db:up && npm run dev` → http://localhost:3100

## Подтверждение действий

Явный запрос пользователя разрешает связанные с ним безопасные действия: чтение,
запуск проверок, редактирование файлов и обычные шаги реализации. Не запрашивай
подтверждение перед каждым таким действием. Отдельное подтверждение требуется
только перед разрушительными или рискованными операциями, внешними публикациями,
изменениями вне оговорённого объёма и действиями с неясной целью или областью.
